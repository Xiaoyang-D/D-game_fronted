# D-Game 游戏社区前端

## 项目介绍

D-Game 是面向游戏玩家的交流社区，将游戏版区、内容创作、玩家互动和好友聊天汇集在同一平台。玩家可以浏览游戏相关内容，分享攻略、心得和创作，关注感兴趣的作者，并与同好交流。

项目由社区前端、业务后端和游戏助手组成。本仓库提供 D-Game 的用户界面，涵盖社区首页、游戏版区、帖子创作、个人主页、消息中心、游戏助手和管理后台。页面采用统一的绿色主题，并适配桌面与移动端浏览。

## 主要功能

### 社区浏览与内容发现

- 首页展示游戏版区和社区内容，提供搜索、关注动态和创作入口。
- 按游戏进入独立版区，浏览论坛、官方、攻略、互助、同人和 COS 等分区。
- 支持推荐内容、最新发布和最新回复等浏览方式。
- 支持搜索游戏与帖子，并选择游戏版区缩小搜索范围。
- 支持浏览公开帖子和作者主页，查看关注作者的动态。

### 内容创作与互动

- 支持富文本图文编辑、图片上传、话题选择和个人合集。
- 支持保存草稿、定时发布，以及查看、编辑和删除自己的帖子。
- 支持评论、楼中楼回复、点赞、收藏和举报。
- 帖子和评论均支持搜索并选择具体用户进行提及。
- 有权限的用户可以删除评论；删除顶级评论会清理整层回复，删除楼中楼评论保留后续回复。

### 账号与个人空间

- 提供邮箱注册、登录、密码找回和已有账号邮箱绑定页面。
- 支持修改昵称、头像和个人简介。
- 个人主页展示发布内容、收藏、关注及粉丝信息。
- 提供每日签到、连续签到状态和奖励补发提示。

### 好友聊天

- 互相关注后展示好友状态，可从个人主页或好友列表开始聊天。
- 好友列表支持昵称搜索。
- 聊天列表展示头像、昵称、最新消息摘要、时间和未读数。
- 桌面端提供会话列表与聊天详情双栏布局，移动端提供独立聊天视图。
- 消息展示发送者头像与昵称，本人消息靠右显示，对方消息靠左显示。
- 支持文字、换行和表情选择，每条消息最多 2000 字符。
- 支持 Enter 发送、Shift+Enter 换行，中文输入法确认时保留正常输入。
- 发送失败时保留正文并支持重试，发送者可在两分钟内撤回消息。
- 支持确认后单方删除会话，收到新消息后会话重新出现。
- 解除好友后保留历史记录，并提示当前无法发送新消息。

### 消息中心

- 提供聊天列表、回复我的、@我的和收到的赞四个页签。
- 聊天列表内提供系统通知及关注与好友通知入口。
- 页签和导航栏统一展示未读数量。
- 支持单条通知已读、当前分类全部已读，以及跳转并定位相关评论。
- 提供回复、提及、点赞、关注与好友四类提醒开关。
- 好友新消息在非当前聊天时显示可点击的站内轻提示。
- 支持实时更新与断线重连后的消息补取。

### 游戏助手

- 提供悬浮聊天入口和独立助手页面。
- 支持用自然语言查找游戏、评分、排行榜和公开社区讨论。
- 支持连续对话、逐步显示回答、查看内容来源及清空历史对话。

### 管理后台

- 提供游戏创建、游戏版区和分区管理页面。
- 支持帖子封禁与解封、评论审核及举报处理。
- 支持用户封禁、解封和角色分配。
